Foundations · LLM

An LLM writes one small piece of text at a time

prompt
The capital of Tamil Nadu is Chennai,acoastalcityontheBayofBengal.

Each coloured piece is a token, roughly three quarters of a word. The model picks the most fitting next token, again and again.

Tokens are also the unit you pay in

Input$4
Output$20

Per million tokens, the rates quoted in our session for a top-tier model. What the model writes costs about five times what it reads.

  • Subscription: a flat monthly fee, like ChatGPT or Claude plans.
  • API key: pay only for the tokens you use.
  • OpenRouter: one wallet and one key for hundreds of models, some of them free.

Foundations · LLM

The context window is the model's working memory

The model remembers nothing between messages. Every turn, the whole conversation so far is sent again.

window full → conversation summarised, detail lost
0each stripe is one more turn272K tokens

It has a size

Common limits run from about 272K tokens to 1 million. The harness shows how full it is, for example 13.4%.

It fills up

At the limit, the harness squeezes the chat into a summary and starts a fresh window. Fine details go missing.

So match it to the job

Short questions fit anywhere. Long projects want the larger window, and a new session per topic keeps things sharp.

Foundations · Harness

The model is the brain. The harness gives it hands.

A model on its own

  • Knows a lot and reasons well
  • Can only produce text
  • Cannot open a file, run a command or browse

What the harness adds

  • Tools: actions it can take, such as the terminal, files and web search
  • Skills: saved instructions for a job it has learned to do
  • Memory and permissions, and it runs the loop
you say“Create a folder called reports.”The model decides the command. The harness runs mkdir reports.
you say“Organise this folder by client.”The model writes a small script for your rule. The harness runs it and reports back.

Hermes is not an LLM. It borrows its intelligence from whichever model you connect.

Hermes · Where it runs

Give the agent a machine of its own

A VPS is a rented computer in a data centre. You will also hear “VM” and “instance”. They mean the same thing here.

Always on

The cloud provider keeps it powered and online. No dead battery, no closed lid.

A safe playground

The agent can create, change and delete freely. If it makes a mess, your own files are untouched and you rebuild the server.

Cheap enough

AWS, Google Cloud and Azure are priced for companies. Hetzner, Contabo and DigitalOcean suit individuals. Ours: 8 GB, in Mumbai, about ₹1,300 a month.

Pick a region near you for faster replies. Two shortcuts exist: Hermes offers a one-click cloud deploy, and it also runs on your own computer if that stays switched on.

Setup

The setup, in six steps

1

Rent a server

A small Linux VPS from any provider.
2

Log in

Connect from your laptop with SSH. It feels like a local terminal.
3

Install

Copy the one-line Linux installer from the Hermes site and paste it.
4

Connect a model

Choose a provider. We signed in with a ChatGPT subscription using a device code.
5

Pick the settings

Choose the model and how hard it thinks. We chose medium.
6

Connect Telegram

Scan a QR code, name your bot, press Save and restart.

On the Mac desktop app, step 6 took about two minutes: scan, name the bot, say hi.

Four habits that keep it safe

  • Read-only first. Let it view mail before it can send or delete.
  • Its own machine. Keep it away from files you cannot lose.
  • Closed ports. Open only what the setup needs.
  • Watch the meter. Tokens cost money, and loops use many.

Start small: one bot, one job, read-only.
