What Cursor adds on top of frontier model tokens

The Cursor Token Rate, which plans it applies to, which models escape it, and why a flat per-token fee hurts cheap models and warm caches hardest. Read from Cursor’s own documentation.

The short answer

Cursor does not charge a percentage markup on frontier model tokens. It passes the provider’s list price through and adds a flat fee on top of every third-party token: $0.25 per million tokens, charged on input, output and cached tokens alike.1

Because the fee is flat rather than proportional, its percentage effect is wildly uneven. On GPT-5.6 Sol output tokens it is a rounding error. On cache reads for a cheap model it is the entire bill.

The part that surprises people: the fee applies to Teams and Enterprise plans only, and it applies even when you bring your own API key.14 Pay OpenAI directly and you still pay Cursor $0.25/M for the privilege.

The markup, in three parts

1. The Cursor Token Rate — $0.25 per million tokens

This is the actual markup. It is charged on input tokens, output tokens and cached tokens for any third-party model request, whether you pinned the model yourself or Auto and Cursor Router landed on it.1

  • Teams and Enterprise only. The documentation attaches it to those plans specifically.1
  • It covers search infrastructure, custom model execution and routing, and processing costs — Cursor’s stated rationale.1
  • First-party models are exempt. Grok and Composer carry no token rate.1 The documentation is direct about the escape hatch: “How do I avoid the Cursor Token Rate? Use a first-party model, including Grok or Composer.”1
  • BYOK does not exempt you. The rate applies to included usage, on-demand usage and BYOK usage alike, and stacks on top of whatever your API provider bills you.1

2. The old request-based plans: Max Mode at model rate + 20%

Legacy request-count plans carry a different structure: Max Mode bills at the model’s API rate plus 20%. New usage-based plans do not have it, and many of the newer models are marked as requiring Max Mode on those legacy plans.3 If you are on an old plan, this — not the token rate — is what you are paying.

3. Auto modes bill at the routed model’s price

There is no hidden multiplier for letting Auto choose. The request is billed at whatever model the router selected, plus the token rate if that model is third-party.1 The cost swings on which model the router picks, not on a surcharge.

The GPT-6.1 Sol problem

There is no Cursor markup on GPT-6.1 Sol, because Cursor does not appear to offer it at all. Cursor’s public model table stops at the GPT-5.6 family — Sol, Terra and Luna — and contains no GPT-6 entry of any kind.3

That makes the question moot for anyone on a subscription: you cannot select a model the picker does not list, so there is no markup to measure. The only conceivable route is BYOK, and Cursor’s own documentation restricts OpenAI keys to “standard, non-reasoning chat models” shown in its picker,4 which a GPT-6.1 Sol entry is not. Adding it would be a pass-through workaround rather than a supported path.

This finding is a snapshot. Model availability changes monthly, and the correct response to it is to re-check the table rather than to trust this page.

Bottom line, by plan

Individual plans (Pro, Pro Plus, Ultra)

Effectively no markup. Included usage is spent at provider list prices, and on-demand continues at the same rates. BYOK on an individual plan does not draw down included usage at all — your provider bills you and Cursor adds nothing.4

Teams and Enterprise

A flat $0.25 per million tokens on every third-party token — input, output and cached — including tokens bought with your own key. The measured effect runs from roughly +1% to +1,250% depending on model and cache mix.1

Legacy request-based plans

+20% on top of the model’s API rate whenever Max Mode is enabled, which many modern models require on those plans.3

Team seat pricing, for context

Standard seats are $40/user/month and Premium seats $120/user/month with five times the usage allowance. Usage does not transfer between team members and resets each billing cycle.2

One detail worth knowing if you are in India: Cursor’s documentation describes a Start plan, “our plan for developers in India”, which covers the first-party Cursor Models pool but does not include the third-party Other Models pool at all.3 That is a structural difference, not a discount.
